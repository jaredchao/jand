# jand 视觉资产探索稿

这组资产基于 jand 的实际用途：跨机器交接任务、端到端加密、由两端用户分别授权，以及交接后的 Agent 协作。当前是可比较的视觉探索稿，尚未选定正式品牌标志。

## 文件

- `logo/relay.svg`：方向 01。开放的两端与中间的移动信号，建议优先评估。
- `logo/continuity.svg`：方向 02。任务跨越间隙后继续。
- `logo/peer.svg`：方向 03。两端独立、中央共享。
- `icons/*.svg`：六个 24 × 24 的操作图标，分别对应发送、接收、加密载荷、对话、检查点和验证回执。
- `preview/identity-exploration.png`：三种标志与图标的 Figma 画板预览。
- `preview/usage-trials.png`：方向 01 的深浅底组合与小尺寸试用预览。
