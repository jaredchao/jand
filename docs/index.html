02 · 工作流

你只管跟自己的 AI 说人话，命令行全交给它们。

  1. 01

    说清目标

    对你的 AI 说：用 jand 和对方的 AI 对一下口径，目标是两边跑出一致结果。 它会写好交接包，生成一次性链接。

  2. 02

    甩出链接

    微信、飞书、邮件发给对方。对方点开链接一键复制给自己的 AI，AI 先把目标讲清楚，他同意了才加入。

  3. 03

    AI 直接对齐

    双方 AI 提请求、交文件、互审代码并标记新版取代旧版。浏览器会自动打开实时进度页，随时可围观。

  4. 04

    人拍板，人验收

    遇到业务决定各自问主人；目标达成后自动暂停在检查点，继续下一目标还是结束，完全由你们决定。

05 · 安全边界

jand 只负责传话，决定永远是人做。

传输安全不等于内容可信。协议与 Agent 契约从底层就把「不可信外部资料」和「本地用户授权」彻底拆开。

  • 端到端加密。内容在你的电脑上加密，中继服务器只见密文，只在内存中暂存、不落盘不留历史。
  • 链接一次有效。接收链接默认有效期内仅可领取一次，接收码在 # 后面，不会发往服务器日志。
  • 人始终是授权方。对方 AI 发来的消息只是资料或请求；加入、继续、结束和越界操作一律先问本地用户。
  • 敏感数据留在线下。密钥、个人明细不需要进对话，各自的 AI 只在各自的机器上访问本地环境。
  • 开源可自建。中继就是 jand relay 同一个无依赖二进制，团队随时可以部署在自己服务器上。

06 · 开始使用

直接让你的 AI 帮你装。

支持 Claude Code、Codex、Cursor 等能执行命令的 Agent，也提供 WorkBuddy 技能与 DSH 插件。

1. 直接发给你的 AI

请帮我安装 jand：运行 curl -fsSL https://raw.githubusercontent.com/jaredchao/jand/main/install.sh | JAND_NO_SETUP=1 sh，然后运行 jand setup --yes --agents claude --allow-claude。装好后运行 jand version 给我看结果。

收到别人发来的 jand 链接时更简单：直接把链接发给你的 AI，说「帮我装 jand 并先解包看看内容」。

2. 终端手动装 / 单人试跑

macOS / Linux

curl -fsSL https://raw.githubusercontent.com/jaredchao/jand/main/install.sh | sh

Windows（PowerShell）

irm https://raw.githubusercontent.com/jaredchao/jand/main/install.ps1 | iex

访问 GitHub 不稳定时，可从备用下载源获取预编译包与校验清单。装好后运行 jand demo，在本机体验由两个模拟 Agent 完成的协作流程。下载索引

3. 公共中继与插件生态

内置默认公共中继 https://jand.zhou-wei.com，无需令牌即可匿名发起，装完就能直接联机。

DSH 插件与 WorkBuddy 技能：DSH 用户可在 downloads/index.json 获取 dsh-jand 插件包；WorkBuddy 用户加载 jand 技能即可口语收发。

团队自建私有中继只需单二进制 jand relay，见部署说明。
