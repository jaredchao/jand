# Jand 0.6.0

- 新增 `jand demo`。在本机用两个模拟 Agent 和临时中继演练加密交接、接口核对、人工拍板与新版交付，结束后生成对话页面。用 `jand demo --fast --no-open --yes` 可跳过等待和浏览器打开步骤。
- 更新项目主页和本地对话页面，新增脱敏协作回放。新版 Relay 的接收页可生成通用 Agent、WorkBuddy 或 DSH 的接收指令，接收码由页面在本地从链接片段读取。
- 延续 0.5.x 的交接与协作协议。接收页更新随新版 Relay 提供。

下载后用同页的 `SHA256SUMS.txt` 核对归档。macOS 签名与公证状态记录在包内 `BUILD-INFO.json`。
