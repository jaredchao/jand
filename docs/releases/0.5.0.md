# Jand 0.5.0

本次整合本地任务控制器、只读 chat inspect、插件分发支持及协作指南。

- `task` 持久维护统筹身份、任务版本、执行与待审容量、排队上限和停止截止；启动或停止结果不确定时保留 unknown，不重派。
- `chat inspect --json` 导出本机时间线、交付关系和统计完整性，不读取 Relay、不推进游标。
- Codex 自动排队提醒返回 `agent_notify_blocked`，不再调用 queue 或自动重试。普通只读 watch 和正式 recv 继续可用。底层通知合并不被当成宿主队列背压。
- 统一对话、统筹与执行分工；停止任务、停止接收和关闭远端对话分开。补齐退出码 4/5 的说明。
- 网络协议保持不变，服务器沿用既有配置、证书和令牌。Relay 重启仍会清空内存临时记录。

验证：Go race 测试、vet、插件支持脚本检查及本地 CLI smoke；DSH 独立 session、执行 subagent、修改/停止及关联命令测试使用真实框架和确定性模型。未操作 UI；AppleScript 解释器专项测试按用户边界跳过。

限制：任务控制器的 OS 锁及受管进程取消支持 macOS/Linux，Windows 明确手动降级。Codex 自动通知保持暂停，主对话任务通知为查询模式。真实模型持续服从、设备 UI 和跨设备长期使用不由自动测试证明。
